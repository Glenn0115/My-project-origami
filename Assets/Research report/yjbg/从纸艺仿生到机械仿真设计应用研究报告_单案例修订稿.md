## 摘要

本研究以自然结构和运动机制的抽象转译为出发点，探索纸艺仿生结构如何转化为可建模、可仿真、可制作和可评价的设计模块。研究以象鼻所体现的连续柔性、轴向伸缩、扭转及分段运动特征为仿生启发，不对象鼻外形进行直接复制，而是提取其中适合结构设计的运动关系，并以 Kresling 折纸构型作为纸艺化和数字化表达的结构载体。

研究首先分析仿生特征与 Kresling 折线构型之间的对应关系，建立从自然运动特征、结构关键词、折线布局到模块参数的转译路径；随后围绕单个 Kresling 模块开展数字建模，并依托 Unity 构建折纸结构的交互式运动仿真环境，用于观察模块在不同折叠状态下的高度、扭转、面片联动和空间形态变化。在此基础上，研究进一步提出基础模块、参数变体和多模块组合的系列化设计方案，初步讨论其在可展开结构、展示装置、柔性机械概念和设计教学中的应用可能与技术边界。

为检验数字设计结果的可制作性，研究制作实体模块样机，并通过初始状态、展开过程和终态三个阶段的运动视频，对数字仿真结果与实体折叠效果进行对照。实体验证重点考察模块是否能够按照预设折线完成展开、收缩和扭转，以及数字模型与实体运动之间是否保持基本的结构对应关系。研究不涉及材料本构、应力应变、承载能力、疲劳寿命或有限元分析，文中所称“机械仿真”主要指服务于结构运动理解、参数比较和设计方案推演的交互式数字仿真。

研究形成了一条“仿生特征提取—Kresling 模块生成—数字建模—交互仿真—系列化扩展—实体样机验证—设计评价”的方法路径。研究结果可为纸艺仿生结构的设计前期推演、模块化产品概念设计以及相关课程的项目式教学提供参考。由于本研究以单一核心模块和单件实体样机为主要验证对象，尚未开展具有统计推断意义的课堂对照实验，相关结论应限定在设计方法可行性、结构运动表达和应用潜力层面。

**关键词**：纸艺仿生；象鼻运动启发；Kresling 折纸；交互式仿真；模块化设计；设计教学

## 第一章 引言

### 1.1 研究背景

仿生设计并不是对自然外形的简单复制，而是从自然对象中提取形态、结构、运动和功能关系，再将这些关系转化为人工设计可以使用的构型、参数和制作方法。纸艺具有材料成本低、制作反馈直观、结构变化容易观察等特点，适合承担仿生观察与设计试作之间的中间媒介作用。

折叠结构尤其适合表达具有展开、收缩、旋转和形态转换特征的自然运动。Kresling 折纸构型由多边形面片和斜向折线形成，其折叠状态通常伴随轴向高度和周向扭转的变化，因此可以作为研究“运动特征如何转化为模块结构”的设计载体[3-4]。

在传统纸艺设计中，研究者往往能够通过手工试作获得直观的形态反馈，但实体试作在参数比较、状态记录和多方案对照方面存在局限。数字建模和实时引擎则可以将折线、面片、折叠角度和模块组合关系转化为可观察、可记录和可重复调整的数字对象。由此，纸艺样机与交互式数字仿真之间可以形成相互补充的设计流程：实体样机帮助理解材料和结构，数字模型帮助比较参数和运动状态。

### 1.2 研究问题

本研究围绕以下问题展开：

1. 如何从象鼻的运动特征中提取适合纸艺结构表达的仿生关键词？
2. 如何将“伸缩、扭转、分段和连续运动”等关键词转译为 Kresling 折纸模块的折线、面片和参数关系？
3. 如何建立 Kresling 模块的数字模型，并在 Unity 环境中观察其折叠、展开和扭转过程？
4. 如何在单个基础模块的基础上形成具有差异化参数和组合方式的系列化设计方案？
5. 数字仿真结果与实体样机运动之间有哪些一致性和差异？这一方法适合哪些设计和教学场景，又有哪些边界？

### 1.3 研究目标

本研究目标包括：

1. 建立以象鼻运动特征为启发、以 Kresling 折纸为结构载体的仿生转译方法。
2. 建立从仿生关键词、折线布局、面片关系到数字参数的模块化表达方法。
3. 构建面向结构运动观察和设计方案推演的交互式数字仿真流程。
4. 基于基础模块形成数字化系列设计方案，并讨论其设计应用场景。
5. 制作实体模块样机，通过运动视频对照数字仿真结果，评价设计的可制作性和运动表达效果。
6. 形成一套可用于设计前期和设计课程的项目式教学方案与过程评价框架。

### 1.4 研究范围界定

本研究的“机械仿真”是设计研究语境中的交互式运动仿真，重点关注几何关系、折叠路径、模块状态、参数变化和设计反馈，不等同于工程级有限元分析、多体动力学定量求解或材料性能预测。

本研究的“设计优化”主要指折线布局、模块几何、折叠路径、模块组合和应用形式的优化，不涉及材料强度、承载能力、疲劳寿命和应力应变优化。

本研究的“系列设计”主要指围绕同一 Kresling 基础单元形成的参数变体、模块组合和应用方案。实体验证以核心模块样机为主，其他系列方案可通过数字模型、结构图和设计说明呈现；只有已经实际制作的方案才表述为实体样机。

### 1.5 研究意义

本研究的意义主要体现在三个方面。第一，在方法层面，尝试建立从自然运动特征到纸艺模块，再到数字仿真和实体验证的连续设计链路。第二，在设计层面，利用 Kresling 模块的轴向—扭转耦合特征，探索可展开、可收缩和可变形结构的系列化设计可能。第三，在教学层面，将仿生观察、纸艺构形、参数建模、数字仿真和实体验证组织为连续任务，为设计基础课程、产品概念设计课程和数字制造课程提供案例基础。

## 第二章 仿生启发与相关理论

### 2.1 从象鼻运动中提取仿生特征

象鼻不宜被理解为一个需要直接复制的外形，而应被理解为一种能够在多个方向上产生连续运动的柔性结构。已有动物运动学和解剖学研究记录了象鼻运动中的曲率、扭转及局部肌束组织等特征[1-2]。结合本研究的设计目标，可从象鼻运动中提取以下四类特征：

1. **轴向伸缩**：结构长度可以在不同状态之间变化。
2. **扭转运动**：结构在长度变化或姿态变化过程中伴随周向旋转。
3. **分段连续性**：整体运动可以理解为多个局部单元共同作用的结果。
4. **姿态可变性**：结构不是固定形态，而是通过内部关系变化产生不同空间状态。

本研究只提取这些具有设计转译价值的运动关系，不声称 Kresling 模块能够完整复制象鼻的生物组织、材料性能或复杂控制机制。

### 2.2 象鼻特征到 Kresling 模块的转译

仿生转译过程可以分为“观察—抽象—映射—校验”四步。

| 仿生观察 | 结构抽象 | Kresling 模块表达 | 可观察结果 |
|---|---|---|---|
| 轴向伸缩 | 长度可变 | 模块高度变化 | 展开与收缩 |
| 螺旋方向运动 | 周向旋转 | 斜向折线与旋转折叠 | 扭转角变化 |
| 分段连续结构 | 局部单元组合 | 单模块串联或叠加 | 多段形态变化 |
| 柔性姿态变化 | 状态可切换 | 折叠参数和连接关系变化 | 不同空间构形 |

在这个过程中，仿生对象提供的是运动启发，Kresling 折纸提供的是结构实现方式，Unity 数字仿真提供的是状态观察和参数比较工具。三者之间不是一一复制关系，而是“运动特征—几何构型—数字表达”的逐级转译关系。

### 2.3 Kresling 折纸构型的设计基础

Kresling 模块通常由环向多边形边界、斜向折线和相邻面片组成。模块的折叠状态受到多边形边数、面片尺寸、折线倾角、初始高度、旋转相位和折叠方向等因素影响[3-4]。Kresling 单元并非理想的纯刚性折叠机构，面片变形、材料和制作条件也可能影响实体运动；本研究将数字面片与关节模型定位为设计阶段的近似表达，而非对实物行为的精确预测[4]。

本研究关注的不是计算某一材料体系的精确力学性能，而是利用这些几何参数建立设计变量，使设计者能够回答以下问题：

- 哪些折线决定模块的基本构形？
- 哪些参数影响模块高度？
- 哪些参数影响扭转方向和幅度？
- 单个模块如何与其他模块连接？
- 数字仿真中的运动状态能否被实体纸样实现？

### 2.4 交互式数字仿真的设计价值

交互式数字仿真的价值主要有三点：

1. 将二维折线和三维面片之间的关系可视化。
2. 通过滑条、状态切换和相机观察比较不同折叠状态。
3. 将参数调整、模型版本和运动结果组织为可追踪的设计过程。

它适合设计前期的结构理解和方案推演，但不能替代实体材料测试，也不能直接给出应力、应变、承载能力或疲劳寿命等工程结论。

## 第三章 研究方法与技术路线

### 3.1 研究类型

本研究采用单案例设计研究方法，以一件 Kresling 纸艺样机及其数字模型为核心案例，综合使用仿生分析、结构分析、参数化建模、交互式仿真、设计变体比较和实体样机验证等方法。

研究的案例单位不是三件不同作品，而是同一作品在不同层级上的表达：

1. 自然运动特征层：象鼻运动启发；
2. 结构模块层：Kresling 单独模块；
3. 整体构形层：由模块或折线关系形成的整体样机；
4. 运动状态层：初始状态、展开过程和终态；
5. 数字表达层：参数、面片、折痕、关节和仿真状态。

### 3.2 研究流程

本研究流程分为八个阶段：

1. 仿生观察：提取象鼻运动中的伸缩、扭转、分段和姿态变化特征。
2. 结构抽象：将自然运动特征转化为模块化结构关键词。
3. 单元生成：建立 Kresling 模块的折线布局、面片关系和初步构形。
4. 数字建模：将模块的顶点、面片、折痕和参数转化为数字模型。
5. 交互仿真：在 Unity 中观察模型的折叠、展开、扭转和状态切换。
6. 系列扩展：围绕基础模块形成参数变体、组合变体和应用变体。
7. 实体制作：制作核心模块样机，并记录初始、展开中和终态运动过程。
8. 对照评价：比较实体与数字模型的运动关系，分析设计有效性和适用边界。

### 3.3 研究材料

本研究材料包括：

- 象鼻运动特征的观察资料和文献资料；
- Kresling 模块结构图和单独模块图；
- 整体纸艺样机；
- 样机运动视频；
- Unity 折纸建模与仿真工程；
- JSON 或其他格式的模型数据；
- 系列化设计方案图和参数记录表。

其中，样机的纸材、厚度、外接尺寸、模块数量、折线数量和连接方式暂列为待补信息。

### 3.4 评价方法

本研究采用以下四类评价：

1. **结构转译评价**：判断仿生特征是否被明确转化为折线、面片和模块关系。
2. **数字表达评价**：判断数字模型是否能够表达设计对象的基本结构和状态变化。
3. **实体运动评价**：观察样机是否能够按照预设结构完成展开、收缩和扭转过程。
4. **仿真—实体一致性评价**：比较数字模型和实体样机在运动顺序、状态变化和结构关系上的一致性。

本稿不使用缺乏原始记录支持的学生问卷、分组实验、均值、显著性检验或教学效果统计数据。

## 第四章 象鼻运动启发下的 Kresling 模块设计

### 4.1 仿生目标的确定

本研究将象鼻作为运动启发源，研究目标不是复刻象鼻外形，而是提取一种“连续柔性结构如何通过局部单元关系产生整体姿态变化”的设计思想。

因此，本研究将仿生目标确定为：在纸艺材料和折线结构允许的范围内，构建能够产生轴向状态变化和周向扭转的折纸模块，并进一步探索多个模块组合后的系列化设计可能。

### 4.2 Kresling 单元的生成逻辑

Kresling 单元的生成可以概括为以下步骤：

1. 确定模块的环向边数和基本轮廓。
2. 确定上下边界之间的对应点关系。
3. 根据旋转相位建立斜向连接折线。
4. 将相邻点之间的连接关系转化为面片。
5. 区分山折、谷折和边界线。
6. 确定模块的初始高度、周向尺寸和折叠方向。
7. 通过纸样或数字模型检查面片是否能够连续闭合。

- 整体样机的主要尺寸。

### 4.5 基于模块的系列化设计

在基础 Kresling 模块确定后，本研究将系列化设计分为三类。

#### 4.5.1 参数变体

通过改变环向边数、模块高度、模块直径、折线倾角、旋转相位和折叠方向，形成具有不同展开幅度和扭转效果的模块方案。

#### 4.5.2 组合变体

通过单模块、双模块、多模块串联以及同向、反向和交替组合，探索从局部伸缩—扭转到连续空间姿态变化的结构方案。

#### 4.5.3 应用变体

将模块设计转化为可展开展示结构、可变形包装、空间装置、柔性机械概念组件和教学演示模型等应用方向。

本研究的实体验证以核心模块样机为主。若系列方案尚未全部制作，应表述为“数字化系列设计方案”或“应用概念方案”，不写成已经完成的实体产品系列。

### 4.6 本章小结

本章建立了从象鼻运动启发到 Kresling 模块构型的转译路径，明确了仿生特征、结构关键词、折线关系和模块参数之间的对应关系，并在单独模块的基础上提出参数变体、组合变体和应用变体三类系列化设计方向。

## 第五章 Kresling 模块的数字建模与交互式仿真

### 5.1 系统目标

本研究的数字系统面向折纸结构的建模、加载、状态观察和交互式运动仿真，目标包括：

1. 将折线、顶点、面片和连接关系保存为可复用的数据对象。
2. 根据模型数据生成三维面片和折痕关系。
3. 通过关节或其他运行机制表达相邻面片之间的折叠关系。
4. 通过统一折叠进度、滑条或交互控件观察模块状态变化。
5. 支持同一基础模块不同参数方案的比较。

### 5.2 数据与模型表达

当前工程以 JSON 等数据结构管理折纸模型，主要表达顶点、面片、折痕、折痕类型、连接关系和参数信息。对于 Kresling 模块，应进一步确保以下字段可以和实体结构对应：

| 结构对象 | 数字字段或对象 | 设计含义 |
|---|---|---|
| 顶点 | vertex | 模块几何位置 |
| 面片 | face | 纸面或刚性近似面 |
| 山折或谷折 | crease type | 折叠方向 |
| 折痕角度 | angle 或 target angle | 状态控制参数 |
| 相邻面关系 | connection 或 hinge | 模块联动关系 |
| 模块参数 | height、radius、phase 等 | 系列化设计变量 |

### 5.3 仿真流程

数字仿真流程包括：

1. 输入或加载模块几何数据；
2. 识别顶点、面片和折痕关系；
3. 生成三维面片和折痕可视化；
4. 根据连接关系生成关节或折叠控制对象；
5. 设定模块折叠进度和参数范围；
6. 运行交互式仿真；
7. 保存初始、展开中和终态截图或视频；
8. 对不同参数方案进行横向比较。

### 6.4 差异来源分析

数字仿真和实体运动之间可能存在差异，主要原因包括：

1. 纸张具有厚度、折痕圆角和材料柔性，而数字模型可能将面片近似为刚性面。
2. 实体制作存在折线位置误差、粘接误差和局部变形。
3. 数字关节参数与实际纸张折痕阻力不完全一致。
4. 实体运动受到手动操作速度和施力方式影响。
5. 数字模型的碰撞和约束参数可能造成穿模、塌陷或运动停滞。

这些差异不是本研究需要隐藏的问题，而是判断模型适用边界和指导下一轮设计优化的重要依据。

### 6.5 本章小结

本章以实体样机和运动视频为依据，建立数字模型与实体运动之间的对照方法。实体验证重点不是证明工程力学性能，而是检验仿生转译后的 Kresling 模块是否具有可制作性、可运动性和基本的数字—实体对应关系。

## 第七章 系列化设计与应用方案

### 7.1 系列化设计方法

系列化设计不是简单增加作品数量，而是围绕一个核心结构建立具有可解释差异的设计家族。其基本路径为：

> 基础模块确定 → 参数变化 → 运动状态比较 → 模块组合 → 应用形式转化

系列化设计应保留共同的 Kresling 结构基因，同时在参数、尺度、组合和用途上形成差异。

### 7.2 设计系列一：参数变化

该系列围绕单个模块展开，重点比较：

- 不同环向边数；
- 不同模块高度；
- 不同折线倾角；
- 不同初始旋转相位；
- 不同折叠方向；
- 不同展开幅度。

建议最终至少选择三个有明显差异的数字方案，并使用统一视角输出对比图。

**图 7-1 Kresling 模块参数变体对比图【待插入】**

### 7.3 设计系列二：模块组合

模块组合可包括单模块、双模块串联和多模块组合。通过改变相邻模块的旋转相位和折叠方向，可以形成不同的高度变化、扭转方向和空间姿态。

对于象鼻仿生的进一步扩展，可将多个 Kresling 模块理解为“分段结构”。单个模块主要表达局部伸缩—扭转运动，多模块组合则可探索连续空间姿态变化。若要表达弯曲，需要进一步引入不同模块的差异化控制；这一点属于扩展方向，不应在单模块验证中提前宣称已经实现。

### 7.4 设计系列三：应用形式

结合模块的可展开和可变形特点，可以提出以下应用方向：

1. 可展开展示结构；
2. 可变形包装或收纳结构；
3. 柔性机械臂或仿生机构的概念单元；
4. 空间装置和交互展示模块；
5. 仿生设计和折纸工程课程的教学模型。

这些方向的价值在于说明研究成果的转化潜力。正式版本应区分“已完成方案”“数字概念方案”和“后续应用设想”。

## 第八章 教学方案与评价框架

### 8.1 教学定位

本研究可以转化为面向设计专业学生的项目式教学单元，适用于结构认知、仿生设计、纸艺设计、产品概念设计和数字建模等课程。教学重点不是让学生完成某一种固定作品，而是让学生经历“观察自然—抽象结构—制作模块—建立模型—观察运动—修改设计”的连续过程。

### 8.2 教学实施流程

教学方案分为五个阶段：

1. **仿生观察阶段**：观察象鼻或其他柔性结构，提取运动关键词。
2. **模块构思阶段**：将运动关键词转化为折线、面片和模块草图。
3. **数字建模阶段**：建立 Kresling 模块数字模型，记录关键参数。
4. **交互仿真阶段**：观察折叠状态，比较参数变体，形成设计判断。
5. **样机验证阶段**：制作纸艺样机，用视频记录运动过程并反思数字—实体差异。

### 8.3 教学成果要求

学生在每个阶段提交过程性成果：

| 阶段 | 学生产出 |
|---|---|
| 仿生观察 | 自然对象观察图、结构关键词和运动分析 |
| 模块构思 | Kresling 折线图、模块草图和参数表 |
| 数字建模 | 数字模型、JSON 或参数文件、建模截图 |
| 交互仿真 | 初始—中间—终态截图、方案比较图和运行记录 |
| 样机验证 | 实体样机、运动视频、差异说明和设计反思 |

### 8.4 过程评价指标

本研究建议采用过程性评价，而不是只评价最终造型：

1. 仿生特征提取是否明确；
2. 仿生特征与折线构型之间是否存在合理对应；
3. 模块参数记录是否完整；
4. 数字模型是否能够表达基本结构；
5. 仿真状态是否具有可观察性；
6. 实体样机是否能够按照设计意图运动；
7. 学生能否解释数字模型与实体样机之间的差异；
8. 设计方案是否形成了有依据的迭代。

### 8.5 教学效果的证据边界

当前没有可核验的学生答卷、问卷、计时表和课堂观察记录，因此本报告不对教学效果作统计性结论。现阶段能够形成的是教学方案、教学任务链和评价指标体系。

如果后续实际开展课堂试用，应保留以下材料：参与人数、任务说明、学生过程文件、教师评价表、作品照片、访谈或反馈记录。只有在这些材料完整后，才能进一步讨论学生理解、兴趣、创新能力或综合素质是否发生变化。

## 第九章 研究成果、边界与应用价值

### 9.1 研究成果

本研究拟形成以下成果：

1. 一套以象鼻运动特征为启发的 Kresling 折纸模块仿生转译方法；
2. 一份单独模块结构图和模块—整体样机关系图；
3. 一件实体纸艺样机及其初始—展开中—终态运动视频；
4. 一套 Kresling 模块数字建模和交互式仿真流程；
5. 一组基于参数和模块组合的系列化数字设计方案；
6. 一套面向设计课程的教学实施方案和过程评价框架；
7. 一份关于设计应用场景和技术边界的分析报告。

其中，实体样机、视频和数字模型的最终数量应按照实际完成情况填写。

### 9.2 设计应用价值

在设计前期，本研究可以帮助设计者先通过纸艺和数字仿真观察结构，再决定是否进入更复杂的工程深化阶段。对于可展开结构、空间装置、包装、展示和柔性机械概念设计而言，这种方法能够降低早期试错成本，并使方案比较建立在较清晰的结构依据上。

在教学中，本研究将抽象的仿生概念转化为可观察的折线和模块，将数字建模与实体制作连接起来，使学生能够同时理解自然启发、结构生成、参数变化和设计验证之间的关系。

### 9.3 研究边界

本研究存在以下边界：

1. 研究以单个核心 Kresling 模块和单件实体样机为主要验证对象，外部推广仍需更多结构和样机支持。
2. 数字仿真主要服务于运动状态和设计比较，不等同于工程力学分析。
3. 单个模块能够表达局部伸缩—扭转关系，但不能完整代表象鼻的连续弯曲、复杂控制和生物材料性能。
4. 系列化设计部分以参数变体、组合变体和应用方案为主，只有实际制作的方案才能作为实体成果表述。
5. 当前尚未形成有原始记录支撑的课堂对照实验，因此教学效果暂以方案和评价框架呈现。

### 9.4 后续研究方向

后续研究可从以下方面推进：

1. 制作不同参数的 Kresling 模块，比较其展开、收缩和扭转差异。
2. 构建多模块串联系统，探索分段控制下的弯曲和连续姿态变化。
3. 改进数字模型中的碰撞、折痕独立控制和多模块联动机制。
4. 通过实体测量记录高度、扭转角和运动时间，建立更严格的数字—实体对照。
5. 开展真实课堂试用，收集学生过程作品和教师评价材料。
6. 在具备材料参数和实验条件后，再与有限元分析或专业动力学工具形成分层验证。

## 第十章 结论

本研究以象鼻的连续柔性、轴向伸缩、扭转和分段运动特征为仿生启发，以 Kresling 折纸构型为结构载体，探索自然运动关系如何转化为纸艺模块、数字模型和实体样机。

研究形成的核心路径为：

> **仿生特征提取 → Kresling 模块生成 → 数字建模与交互仿真 → 系列化设计扩展 → 实体样机制作 → 仿真与实体对照 → 设计和教学应用评价**

该路径的价值不在于直接替代工程力学分析，而在于为设计前期提供一种可观察、可调整、可制作和可反思的中间层方法。通过单独模块和实体样机的对照，可以进一步判断数字仿真是否准确表达了折线关系和运动顺序；通过参数变体和模块组合，可以讨论 Kresling 结构从单元设计向系列化应用扩展的可能。

在现有材料和研究范围下，本报告能够支持的结论是：以象鼻运动特征为启发、以 Kresling 折纸为载体的模块化设计，具有开展数字建模、交互仿真和实体样机验证的可行性；其在设计前期和教学中的应用具有进一步探索价值。但由于研究主要依托单件核心样机，且尚未形成课堂量化实验数据，关于普遍教学效果、工程性能和大规模应用的结论仍需后续研究验证。
