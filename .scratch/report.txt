

从纸艺仿生到机械仿真设计应用研究报告
摘要
纸艺仿生是将自然界中的形态规律、结构逻辑与运动特征转化为可设计、可制造、可验证纸质结构方案的一种综合性设计路径。随着数字建模、参数化设计和实时仿真工具的发展，纸艺结构研究已不再停留于静态造型表达，而逐步延伸至结构认知、运动模拟、方案比较与应用转化等层面。基于此，本文围绕“纸艺仿生结构如何从形态提取走向数字建模与交互式机械仿真应用”这一问题展开研究，在保留纸艺材料低成本、易试错、强可视化优势的基础上，构建“仿生提取-纸艺构形-参数建模-交互仿真-应用验证”的研究路径。研究重点放在课程创作与设计前期常见的半立体纸艺仿生作品上，尝试将学生在课程中形成的多种设计方案转译为可观察、可比较、可辅助修改的数字结构对象。
本文综合采用文献分析法、案例分析法、设计实验法和教学验证法，对纸艺仿生结构的类型、构建方法、参数表达与仿真机制进行系统梳理。研究重点包括三个方面：一是提出纸艺仿生结构的建模与设计方法，明确形态提取、结构拆解与参数约束之间的对应关系；二是构建基于 Unity 的交互式仿真系统，建立纸艺特征与数字参数之间的映射关系，用于对课程中的多种半立体作品进行动态展示、参数观察与方案反馈；三是在小样本探索性实验中，对该路径在结构理解、参数探索与教学应用层面的可行性进行初步验证。本文所称“机械仿真”，主要指服务于结构运动理解、参数反馈和设计比较的交互式数字仿真，不等同于高精度工程有限元分析。
研究结果显示，在当前实验条件下，交互式仿真对课程中的半立体纸艺作品理解和方案比选初步呈现出一定辅助潜力。结构理解实验中，交互组在平均正确率、完成时间和理解评分上的均值整体好于传统组；参数探索实验显示，针对作品A这类具有可调折叠关系的半立体结构进行可视化调整，有助于识别相对更合理的结构区间；教学应用实验显示，基于课程创作与交互仿真的学习方式在理解难度、学习兴趣和学习意愿等指标上呈现出较积极的体验倾向。考虑到样本规模、实验设计和研究定位，本文将上述结果界定为对研究路径可行性的初步支持，而非普遍适用的最终结论。基于以上研究，本文形成了面向设计前期与教学应用的纸艺仿生研究框架，并对其方法边界、应用潜力与后续优化方向进行了讨论。
关键词：纸艺仿生；交互式机械仿真；结构建模；参数化设计；教学应用

第一章 引言
1.1 研究背景
仿生学强调从自然界中提取形态、结构、功能与行为规律，并将其转化为人工系统的设计依据。自 Benyus 提出“向自然学习”的系统性仿生观念以来，仿生设计已广泛进入工业设计、建筑设计、机器人、包装与材料创新等领域[1]。在这一背景下，纸艺因其材料轻便、加工直接、成本较低、结构反馈明显等特点，逐渐成为连接仿生观察、快速原型和结构表达的重要媒介。
纸艺结构不仅具有艺术表现属性，还具备清晰的几何关系与运动逻辑。折叠、切割、拼接、层叠等纸艺技法能够快速呈现单元重复、弹性开合、展开收纳和局部支撑等结构特征，因此在折纸工程、可展结构、轻量化产品概念设计以及教育实验中具有独特价值[2-4]。尤其是在设计研究的早期阶段，纸艺模型可以承担“快速试错”和“直观反馈”双重功能，为后续数字化建模提供清晰的结构依据。
与此同时，数字建模与交互仿真工具的发展正在改变纸艺结构的研究方式。过去纸艺研究多集中于造型或工艺表达，较少关注结构参数、动态行为和可重复验证；而在参数化设计和实时引擎介入后，纸艺结构可以被进一步转化为可计算、可比较、可迭代的数字对象。以 Unity 为代表的实时仿真平台，能够通过刚体、关节、碰撞和参数交互等机制，帮助研究者在设计阶段观察结构运动轨迹、比较不同参数方案，并对设计结果进行可视化反馈[5]。
然而，现有研究在从纸艺仿生走向数字建模、交互仿真与教学应用的过程中，仍存在三个较为突出的缺口。第一，纸艺到数字转译缺方法。现有研究要么停留在造型表现和手工经验层面，要么直接进入工程分析，缺少将纸艺样机拆解、编号、参数化并转译为数字模型的中间层方法。第二，仿真应用多停留在展示层。设计与教学中的数字系统往往偏重静态呈现或简单动态演示，对结构行为、参数关联和方案比较的支撑仍不充分。第三，教学验证证据不足。虽然纸艺、数字工具与课程改革的讨论日益增多，但围绕结构理解、参数探索和教学效果形成的过程性证据仍较少，导致相关路径的可复核性与推广说服力有限。基于此，有必要围绕纸艺仿生结构的设计方法、交互仿真定位与教学验证机制展开更系统的研究。
1.2 研究问题与研究目标
为避免题目中的“机械仿真”引发误解，本文先作界定：本文所称“机械仿真”，主要指服务于结构理解、动态展示、参数比较和方案辅助的交互式数字仿真，不等同于面向承载分析、材料非线性求解和工程定值预测的高精度工程仿真；题目中的“设计应用”主要指设计前期方案推演、课程创作辅助以及教学情境中的设计实践应用。在这一边界下，本文主要关注以下四个研究问题：
1. 如何从自然界对象中提取适合纸艺表达的仿生结构特征，并建立清晰的转译规则？
2. 如何将纸艺构形过程，尤其是课程中常见的半立体创作方案，转化为可参数化、可比较、可复现的数字模型？
3. 如何结合交互式机械仿真手段，对多种半立体纸艺结构的运动行为、空间关系和方案差异进行直观验证？
4. 如何在设计前期与教学验证场景中评估该路径的实际表现、应用潜力与适用边界？
据此，本文的研究目标可概括为以下四点：
1. 提出一套面向纸艺仿生结构的建模与设计方法，形成从仿生提取到纸艺表达再到数字建模的完整链路。
2. 构建基于 Unity 的交互式仿真系统，实现对课程中多种半立体纸艺作品的结构关系、参数变化和状态切换的可视化反馈。
3. 通过小样本实验和案例应用，对该方法在结构理解、参数探索和设计辅助层面的可行性进行检验。
4. 总结纸艺仿生结构在设计研究、课程实验和应用转化中的适用范围、局限性与优化方向。
1.3 研究意义
本文的研究意义主要体现在以下三个方面。
第一，理论层面上，本文尝试将纸艺仿生、数字建模与交互仿真放入同一研究框架中讨论，弥补纸艺结构研究长期停留在造型表达而缺少结构验证路径的问题。通过引入“结构单元拆解+参数约束重构”的方法，本文为纸艺仿生结构的系统化研究提供了更清晰的论述方式。
第二，方法层面上，本文强调纸艺不仅是造型载体，也是设计验证媒介。通过把纸艺样机、数字模型和交互仿真结果联系起来，可以在较低成本条件下完成方案生成、结构理解和参数比较。这种方法对于概念设计、课程实验和研究原型开发具有较强的可操作性。
第三，应用层面上，本文提出的研究路径既可服务于设计实践，也可延伸至教学场景。对于设计专业而言，纸艺仿生与交互仿真的结合有助于强化结构认知和设计推演；对于课程改革而言，该路径可为项目式学习、实践性评价和跨媒介表达提供具体工具支持。
1.4 研究内容与技术路线
本文的研究内容主要包括以下五个方面。
1. 梳理纸艺仿生、机械仿真、折纸工程与交互仿真相关研究，为本研究建立理论基础。
2. 对纸艺仿生结构的类型、提取方法、构建方式和数字建模路径进行归纳，提出适合本研究的设计方法。
3. 基于 Unity 构建交互式仿真系统，实现纸艺结构的动态展示、参数调节、方案对比与结果反馈。
4. 通过实验与案例检验该路径在结构理解、参数探索和教学应用中的可行性与适用边界。
5. 在综合分析基础上总结研究成果、适用边界与后续发展方向。

1.5 论文结构
全文共分九章。
第一章为引言，主要说明研究背景、研究问题、研究目标、研究意义及技术路线。第二章为文献综述，围绕纸艺仿生、折纸工程、机械仿真、实时交互仿真与设计教育研究进行梳理，并明确本研究的切入点。第三章为研究方法与技术路线，重点说明研究框架、研究方法和实验设计思路。第四章为纸艺仿生结构建模与设计方法，阐述纸艺结构的类型、仿生提取方法、构建路径和建模策略。第五章为基于 Unity 的交互式仿真系统设计，介绍系统目标、架构、关键技术与适用边界。第六章为实验与验证，通过三组实验对研究路径进行探索性验证。第七章为融合设计方法与教学应用策略，对方法模型、流程组织和教学应用进行整合。第八章为研究成果与应用价值，总结主要研究贡献、方法成果及应用前景。第九章为结论与展望，对全文进行归纳，并提出后续研究方向。
第二章 文献综述
2.1 纸艺仿生与折纸工程研究现状
近五年，国际折纸工程研究已经从“几何可折叠”逐步转向“几何—材料—制造—测试”一体化框架。Misseroni等在《Origami engineering》中指出，折纸工程已形成涵盖理论基础、仿真工具、制造技术与非标准测试流程的系统方法链，研究对象也由传统薄片折叠扩展到可展结构、机械超材料、机器人与医学器械等多个方向[13]。这一变化意味着折纸不再只是形态生成手段，而是成为连接结构设计、性能调控与应用验证的重要工程方法。
从力学与功能层面看，折纸/剪纸启发的机械超材料研究是近五年的重要增长点。Zhai等将相关研究归纳为纯折纸、纯剪纸以及折剪混合三类，并指出其关键优势在于通过折线网络与切割拓扑实现可编程刚度、负泊松比、形态重构和多稳态行为[14]。Melancon等进一步实现了米级多稳态充气折纸结构，证明折纸单元可以从实验室尺度走向应急 shelter、拱架等大尺度可展系统[15]。2024年的多项研究又将这一方向继续推进：Zhu和Filipov提出可承载的大尺度厚板折纸结构，强调“可部署+可重构+可承载”的统一[17]；Li等提出分层折纸超结构，使单一系统在较少驱动自由度下实现大量三维构型切换[18]；Wang等则通过刚性双稳单元构造可重构多稳态结构，展示了折纸结构在机器人肢体与可变性能超材料中的潜力[19]。
在仿生方向，近期综述研究开始更明确地把生物形态、行为与折纸工程联系起来。Fakhari等从动物、植物到DNA折纸建立了一个生物启发折纸分类框架，指出仿生折纸不仅服务于形态模仿，更服务于可持续材料、软体机器人与生物启发机构设计[16]。这说明当代纸艺仿生研究的重点，已经从“像不像自然”逐步转向“是否提取了自然对象的结构逻辑、运动机制与环境适应性”。
国内相关研究也在同步转向结构与工程视角。方虹斌等系统回顾了折纸结构和折纸超材料动力学研究，指出该领域已从几何设计与运动学分析延伸到动力学建模、有限元分析、实验辨识以及双稳态/多稳态响应研究[20]。蔡建国、王玉涛则从空间结构视角梳理了新型可展与折叠结构在几何构成、展开路径、受力性能与工程应用方面的进展，强调理论分析、数值模拟和物理模型实验需要并行推进[21]。与此同时，彭玉鑫关于当代纸艺表现技法的研究表明，国内纸艺实践层面已不再局限于传统手工媒介，而是在空间装置、综合材料与结构表达中呈现明显的跨媒介趋势[11]。这些中文文献共同说明，国内研究已经具备由纸艺表现走向结构研究的基础，但在参数化表达、统一验证框架和交互仿真衔接方面仍有进一步深化空间。
总体上看，国外研究在这一领域更偏向工程结构、材料响应和可部署系统等问题，国内研究则更多积累在纸艺表现、课程实践和跨媒介表达方面。两者各有优势，但围绕设计前期与教学场景所需的“纸艺样机-数字模型-交互验证”中间层方法仍未真正打通。
2.2 机械仿真与实时交互仿真研究现状
机械仿真在传统工程语境中仍以有限元分析、多体动力学和实验标定为核心，其目标是获得材料、边界条件和结构响应之间更稳定的定量关系[13][20]。对折纸与仿生结构而言，这类研究特别关注折线转角、面板厚度、连接约束与非线性响应对承载、稳定性和展开路径的影响[14][17][21]。因此，从严格意义上说，工程级机械仿真强调的是“精确预测”，而不是“设计沟通”本身。
但近五年另一个明显趋势是，仿真开始从离线分析扩展到实时交互、数字孪生和可视化决策支持。Goodwin等在数字孪生研究中提出 predictive simulation learning，将离线训练与实时仿真执行结合，以降低实时优化的计算负担[22]。Rundel与De Amicis构建了基于SUMO、GIS与Unity的数字孪生框架，证明游戏引擎可以作为仿真结果与三维场景交互展示的中间层，在单机条件下实现接近实时的场景推演[23]。Shi等进一步开发了Unity-VISSIM协同仿真平台，通过沉浸式交互环境研究多主体驾驶行为，显示Unity类引擎在“行为记录+情境构建+实时反馈”方面具有独特优势[24]。到2025年，Gong和Ding的Unity城市交通数字孪生系统已能在GPU加速和LOD策略下支撑上千实体并发、60 FPS级别的实时交互[25]。这些研究虽然主要发生在交通与城市系统领域，但它们共同揭示了一个稳定方向：实时引擎正在成为“高精度计算”和“设计可视化决策”之间的重要桥梁。
这类研究对本文的启示在于，实时仿真并不一定追求替代工程求解器，而更适合承担三项任务：第一，把抽象结构行为转化为可观察的动态过程；第二，把参数变化与形态反馈建立直接对应关系；第三，为方案比较和教学演示提供低门槛、高反馈的实验环境[22-25]。对于纸艺仿生结构而言，这种中间层仿真的价值尤其突出，因为其研究早期往往更需要“快速试错”和“行为理解”，而不是一开始就追求高精度承载结论。
也正因如此，本文若保留 Unity 方案，其理由并不在于替代纯 CAD 或 FEA 平台。纯 CAD 平台更适合几何建模、尺寸控制和制图表达，FEA 平台更适合应力、承载和材料响应等高精度工程分析；相比之下，Unity 更适合本文所强调的实时交互、状态切换、参数比较和教学演示，因此更符合“中间层仿真工具”的研究定位。
2.3 设计教育与数字化教学相关研究
设计教育领域的近五年研究显示，数字工具的介入并不只是提高效率，更在改变 studio 教学的组织方式、证据形式与评价逻辑。Lee等在建筑设计教学实验中发现，仿真辅助环境会直接改变学生的迭代模式与问题判断方式，并提出设计平台应具备实时、非侵入式的性能反馈与分支比较能力[26]。Soomro等关于数字制造空间的研究则表明，开放式原型制作能够同时提升技术技能与创造力，说明“动手制作+数字工具+多轮迭代”比单一软件教学更有助于设计能力形成[27]。这些国际研究为本文把纸样试制、参数建模与交互仿真放在同一学习链路中提供了方法论依据。
国内设计教育研究同样在强调“新文科”“艺科融合”与数字化转型。吴帆等以北京联合大学为例指出，应用型数字媒体艺术人才培养需要同步重构培养目标、课程体系与实践创新平台，避免学科交叉停留在口号层面[28]。孟祥斌从常州工学院案例出发，强调数字媒体艺术教育应通过跨学科课程、项目实践和平台协同实现技术与艺术的共同训练[29]。王晶等在“艺科融合”课程群研究中进一步提出，设计学类课程建设需要把材料、结构、算法、视觉表达与数字化教学手段统筹起来[30]；邢月、高喜银则直接指出，通用人工智能和数字化信息技术正在推动环境设计教学从结果导向转向“过程可追踪、交互可验证、评价可量化”的新模式[31]。这些中文文献并非只是教学口号，而是在课程组织、能力结构与评价证据层面为本文研究提供了较直接的教学背景支撑。
总体来看，设计教学的关键变化不是简单的软件替换，而是从师徒式、静态展示式教学逐步转向项目驱动、过程留痕、工具协同和跨学科整合的学习机制[26-31]。这意味着，若要让纸艺仿生研究真正进入课程与实验场景，就不能把纸样制作、数字建模和仿真验证分散在不同教学环节，而需要建立一条能够连续传递结构认知与参数证据的链路。
从评述逻辑看，国外相关研究更多强调工具如何介入设计判断与实验环境构建，国内研究则更强调课程改革、艺科融合与教学组织方式更新，但两者都较少把纸艺样机、参数模型、交互仿真和过程性评价整合为同一条可复核的证据链。

2.4 现有研究的不足
综合上述研究可以看到，当前文献格局已形成较清楚的分工：国外研究更多提供工程结构、性能机制与实时仿真的方法基础，国内研究则更多积累在纸艺表现、课程改革与教学应用层面。二者各自推进明显，但面向设计前期与教学场景的中间层方法仍未充分建立。需要说明的是，本章在保留少量经典文献作为概念背景的同时，判断当前研究格局主要依据近五年代表性研究，尤其是 2021-2025 年文献[11][13-31]。据此，现有研究的不足可进一步压缩为以下三个方面。
1. 纸艺到数字转译缺方法。国外折纸工程与结构研究能够处理复杂构型、材料机制和性能问题，国内纸艺研究则在表现技法与课程实践方面积累较多，但两者之间缺少一套把纸艺样机拆解、编号、参数记录并转译为数字模型的中间层方法[11][13-21]。
2. 仿真应用多停留在展示层。实时交互与 Unity 类平台已证明其在动态观察和情境推演中的优势，但现有应用对象多集中于交通、城市等领域；在设计与教学场景中，数字工具也常停留于静态呈现或简单演示，尚未充分形成面向纸艺结构的参数比较、方案反馈和设计辅助机制[22-25]。
3. 教学验证证据不足。现有设计教育研究对课程改革、艺科融合和数字化教学已有较多讨论，但围绕结构理解、参数探索和学习效果所形成的评分表、日志、问卷与过程性证据链仍相对不足，使相关路径的可复核性与推广说服力受到限制[26-31]。
2.5 本研究的切入点与创新定位
基于上述文献，本研究将切入点放在纸艺仿生结构的“中间层方法”建构上，即在仿生观察与工程分析之间引入一个可试制、可转译、可交互验证的研究链路。换言之，国外研究所提供的工程与实时仿真方法，和国内研究所积累的纸艺表现与教学场景，为本文奠定了两端基础，而本文希望补足的正是这两端之间长期缺位的中间层方法。
1. 在研究对象上，选择纸艺仿生结构这一兼具低成本试制、清晰几何关系与教学可操作性的中间媒介，连接仿生观察与数字验证。
2. 在方法路径上，强调“仿生提取—纸艺构形—参数建模—交互仿真—应用验证”的连续链路，把国外文献中较强的折纸工程/实时仿真方法与国内文献中较强的纸艺表现/教学基础结合起来[11][13-31]。
3. 在平台与仿真定位上，明确本文所说“机械仿真”主要是服务于结构理解、参数比较与方案反馈的交互式数字仿真，不与工程级有限元分析混同；同时选择 Unity 作为交互实现平台，重点看中其在实时反馈、状态切换、方案比较与教学演示上的适配性，而非以其替代纯 CAD 或 FEA 平台。
4. 在验证方式上，采用小样本探索性实验与教学应用相结合的方式，关注结构理解、参数探索和教学适配，并通过任务记录、参数日志、截图和问卷等材料形成较完整的过程证据链，而非直接宣称工程性能最优化。
第三章 研究方法与技术路线
3.1 整体研究框架
本文采用“理论分析-方法构建-系统实现-实验验证-总结提升”的整体研究框架。理论分析部分用于构建概念边界和研究依据；方法构建部分用于完成纸艺仿生结构的分类、提取和建模；系统实现部分用于搭建交互式仿真平台；实验验证部分用于检查该平台在设计应用与教学情境中的可行性与适用边界；总结提升部分则用于归纳研究贡献、应用潜力与后续方向。
从结构上看，本文同时包含设计研究和应用验证两个层面。设计研究主要回答“如何做”，应用验证主要回答“这样做是否可行、适用于什么场景”。两者并行推进，既保证了方法论的完整性，也增强了研究结果的落地性。

3.2 研究方法
本文主要采用以下四种核心研究方法，并辅以系统实现与比较归纳作为技术支撑。
1. 文献分析法。通过梳理纸艺仿生、机械仿真、折纸工程、交互仿真和教学验证相关文献，明确研究现状、理论边界和问题缺口[1-6][9-31]。
2. 案例分析法。选取典型纸艺结构、折纸工程案例以及课程中的代表性半立体作品，分析其中的结构规则、参数特征和实现路径，为本文方法建构提供参照。
3. 设计实验法。通过纸艺样机制作、数字建模和交互仿真操作，对课程创作中不同结构与参数方案进行探索性比较。
4. 教学验证法。以设计相关专业学生为对象，结合课程中的半立体作品，通过小样本对照实验收集结构理解、参数探索和使用体验数据，对方法的教学适配性进行初步验证。
其中，文献分析法主要服务于第二章的问题界定，案例分析法与设计实验法主要服务于第四章和第五章的方法构建与系统实现，教学验证法主要服务于第六章的效果验证；比较归纳则贯穿第七至第九章，用于形成方法模型、教学策略和结论表述。
3.3 技术路线设计
本文的技术路线可分为五个连续阶段。
1. 仿生提取阶段。选择具有代表性的自然原型，分析其形态特征、运动方式和结构关系，提取可纸艺化表达的关键元素。
2. 纸艺构形阶段。将提取结果转化为纸艺结构单元，通过折叠、切割、拼接和层叠等方法形成可操作样机。
3. 参数建模阶段。对纸艺结构进行拆解与重构，将折角、单元尺度、连接方式和层级关系转化为可控制参数。
4. 交互仿真阶段。将数字模型导入 Unity 环境，利用刚体、关节、碰撞和交互界面进行动态模拟与方案比较。
5. 应用验证阶段。通过实验与案例使用，评估该路径在结构理解、设计辅助和教学应用中的可行性。
从证据链组织上看，前两个阶段主要产出纸艺样机与结构记录，中间两个阶段主要产出参数模型与交互仿真结果，最后一个阶段主要产出实验数据、问卷结果与过程性记录。这样安排的目的，是使“方法提出-系统实现-应用验证”之间能够形成较清晰的对应关系。

3.6 问卷设计与统计说明
教学应用实验使用五级 Likert 问卷收集主观体验数据。问卷共设置 3 个封闭式核心条目，分别对应“理解难度”“学习兴趣”“学习意愿”三个指标；此外另设 1 个开放式反馈题，用于收集参与者对学习方式优缺点的补充意见。封闭式条目中，“理解难度”为反向判断，均值越低表示越容易理解；“学习兴趣”和“学习意愿”为正向判断，均值越高表示体验越积极。
需要说明的是，本文未对该问卷进行内部一致性信度分析。原因有二：其一，本研究中的 3 个封闭式条目分别对应三个不同维度，目的在于分项描述体验倾向，而非构成一个单一潜变量的综合量表；其二，样本量仅 10 人，研究定位为探索性教学验证，采用描述性统计更符合当前证据强度。因此，本文对问卷结果主要报告原始分数、分项均值、标准差，并结合开放式反馈进行解释，而不据此进行量表结构推断。后续若扩大样本，可将每个维度扩展为多条目量表，并进一步补做信度与效度检验。

第四章 纸艺仿生结构建模与设计方法
4.1 纸艺仿生结构类型分析
结合自然原型特征、纸艺技法属性和数字建模需求，本文将纸艺仿生结构划分为以下三类。
1. 折叠类结构。以折线和开合关系为主要特征，适合表达收展、联动和面间转折关系。
2. 展开类结构。以切割、翻起和层级展开为主要特征，适合表达平面向半立体或立体的过渡关系。
3. 单元类结构。以重复单元和模块组合为主要特征，适合表达规律性支撑、参数变化和系统性构形。
这三类结构并非完全割裂，而是在实际设计中经常交叉使用。分类的目的在于为后续建模与参数设定提供更清晰的分析入口。以下以作品A为例展开说明。作品A为本文研究与系统验证中持续使用的一件半立体纸艺样机，已完成实体试作、参数记录与数字转译。其结构并非对单一自然物种的外形复刻，而是综合提取自然界中常见的“中心汇聚-中心对称-环向展开”关系，并通过中心主轴线、对角联动折线与环向连接折线组织整体开合，适合作为从仿生观察到数字建模的完整示范链。
4.2 仿生原理与结构提取方法
纸艺仿生的关键不在于简单复制自然外形，而在于提取其可转化的结构逻辑。为增强方法的可复现性，本文将“观察-抽象-映射-校验”流程落实到作品A的形成过程中。作品A的选择主要基于三点：其一，结构来源清晰，可追溯到聚拢-展开型层片关系与对称转折逻辑；其二，构形主要通过折叠形成开合与层级变化，便于展示单一折纸工艺下的转译方法；其三，已完成实体样机试作，并在 Unity 环境中开展数字建模和交互验证。
围绕作品A，本文将仿生提取分为三个层次。第一是形态层提取，即识别中心汇聚轮廓、中心对称关系、环向重复节奏和边缘转折，并将其归纳为适合纸艺表达的平面边界与折线骨架。第二是功能层提取，即关注结构在半展开状态下所形成的开合、支撑、过渡和阵列联动关系，并判断哪些功能需要通过纸艺模块保留，哪些可以在转译时做适度简化。第三是机制层提取，即分析各模块如何围绕中心主轴线产生转折、聚拢或联动，并把这类关系转译为主轴线、对角联动折线、环向连接折线、模块交点和折叠层级。

4.3 纸艺结构构建方法
纸艺结构构建是仿生提取转化为实体样机的关键步骤。以作品A为例，其纸艺构建并不是一次完成的，而是经过“中心控制区建立-环形模块布置-联动折线组织-边界定形”的过程逐步形成。根据图 4-2 所示结构关系，作品A是一个中心对称的图形，可看作由多个重复模块围绕中心控制区形成的模块化环形阵列。整体由中心主轴线、对角联动折线、环向连接折线、P1-P8 环形阵列模块以及 B1-B4 外边界定形单元共同构成。这样的构成方式既突出其中心对称特征，也使模块之间的联动路径和编号逻辑更适合后续参数记录与数字转译。
在首轮构形中，首先采用折纸法建立整体折叠框架，通过 2 条中心主轴线（M1-M2）确定上下与左右的对称控制关系，再通过 2 条对角联动折线（D1-D2）和 8 条环向连接折线（A1-A8）把中心控制区与外部模块连接起来。随后根据模块间距、顺时针编号顺序、对称关系和边界跨度调整各阵列单元之间的层次关系，使原本较为平面的折线网络逐步形成稳定的半立体体量，并在展开状态和聚拢状态下都保持较清晰的造型特征。为便于后续比对，试作阶段同步记录了模块编号、折线类型、连接位置和阵列顺序。
从示范链来看，折纸法既负责建立基本运动逻辑，也负责组织环向重复与整体定形。通过这种单一工艺路径，作品A不再只是一个静态造型，而是转化为包含“中心主轴线控制-对角联动-环向模块阵列-外边界定形”关系的可分析结构样机。

4.4 数字建模路径与参数化表达
数字建模的目标不是单纯复制纸样，而是建立可被分析和调整的结构模型。为此，本文采用“结构单元拆解+参数约束重构”的建模思路，并以作品A完整演示该过程。需要说明的是，本章所称“CAD/参数化”并非指依赖复杂工业 CAD 曲面建模，而是指一条更贴合本研究定位的轻量化操作路径：先依据纸样测量结果建立参数记录表与尺寸校对表，再在 Unity 2022.3.62f1 的折痕编辑模块中录入二维折痕关系，随后将数据保存为 OrigamiModel JSON 模型，并由系统自动完成面片重建、折痕约束和三维显示。这样的路径既保留了几何控制能力，也能直接衔接第五章所述交互式仿真系统。
第一步是结构单元拆解。根据纸样记录，将作品A的中心控制区、P1-P8 环形阵列模块和 B1-B4 外边界单元分别编号，同时记录各模块之间共享的折线、折线交点和环向顺序。对于只起视觉装饰作用、不会直接参与开合的细碎边缘，则在数字建模时进行适度合并，以避免后续面片重建过于复杂。
第二步是参数记录。本文并不试图把纸样的所有细节都转成参数，而是优先记录会影响结构理解、中心对称控制和状态切换的关键变量，包括中心主轴折角、对角联动折角、模块分布半径、环向连接折线间距、阵列顺序、模块数量以及必要的刚度假设。实际记录时，长度参数以毫米为单位、角度参数以度为单位，并通过参数记录表与尺寸校对表同步保存纸样测量值和修正值。
第三步是参数约束重构。将上述记录转换为数字模型时，先用顶点和边界边重建平面轮廓，再根据模块编号生成面片关系，并把中心主轴线、对角联动折线、环向连接折线和折线交点分别映射为可控制的数字约束。对于作品A而言，中心主轴线主要对应整体聚拢与展开控制，对角联动折线负责相对方向的同步变化，环向连接折线则通过相邻模块和边界单元关系共同表达环形阵列的局部过渡。这样处理之后，数字模型既保留了作品的核心结构逻辑，又能在交互界面中被调节和比较。
参数化的优势在于，它使设计者能够在不彻底重建模型的前提下，对关键参数进行局部调整，并观察结构行为的变化趋势。对于后续的交互仿真而言，这种参数建模也是实现动态调节和方案比较的前提。更重要的是，通过“编号-记录-映射”的步骤，课程中的半立体作品不再停留在手工试作层面，而能够形成可复查、可复用的中间数据链。

4.5 建模过程中的关键问题与解决策略
在建模过程中，作品A的首轮转译并非一次成功，而是暴露出若干具有代表性的问题。正是这些“失败-修正”过程，使第四章的方法不仅停留在原则层面，也更接近可复现的工作流程。
1. 边界与折线混淆问题。首轮录入时，部分边界线、对角联动折线与环向连接折线未被明确区分，导致数字草模在面片生成阶段误识别出无效闭合区域。对此，本文在记录表中增加“边界边/主轴线/联动折线/环向折线”四类标记，并在数字端优先过滤外部边界，从而提高面片识别的稳定性。
2. 局部碎片过多问题。作品A的局部边缘最初保留了较多装饰性小片和短折线，这些构件虽能增强视觉层次，但在数字重建时容易造成面片过碎、连接关系冗余和后续联动不稳定。对此，本文在保证主结构逻辑不变的前提下，将非驱动性细节合并为较大的表现单元，只保留与开合行为直接相关的核心构件。
3. 对称轴与尺寸偏差问题。手工制作的纸样在中心对齐、左右展开宽度和折线交点位置上存在一定误差，若直接照录，会导致数字模型与实体逻辑不一致。对此，本文采用“测量值-修正值”双记录方式，以中心轴线和关键折线交点为校正基准，优先保证结构关系的一致性，再对局部尺寸做近似修正。
4. 运动与层级关系脱节问题。首轮数字转译更关注折叠角度，导致局部层级变化在模型中只被当作几何附属，而没有进入参数约束逻辑。修正时，本文将关键折叠顺序和层级关系纳入参数记录，使其既参与空间层次表达，也参与状态判断，从而减少“纸样能成立、数字模型却难以解释”的情况。

4.6 本章小结
本章围绕纸艺仿生结构的分类、提取、构建与建模展开论述，并以作品A为示范，将“观察-抽象-映射-校验”和“结构单元拆解+参数约束重构”两套方法落实为可追踪的操作链。通过形态来源与结构提取示意、纸艺样机构成、关键参数表、样机到数字模型的对应关系以及失败修正对照，本章进一步明确了从结构观察到纸艺样机再到数字模型的基本方法，为后续交互式仿真系统的实现奠定了结构基础。
第五章 基于Unity的交互式仿真系统设计
5.1 系统设计目标
本文构建的交互式仿真系统主要面向设计研究与教学验证场景，依托 Unity 2022.3.62f1 引擎，围绕“折痕构形-数据存储-三维重建-折叠仿真-交互反馈”的流程搭建原型平台。系统的服务对象并非单一演示原型，而是课程中的多种半立体纸艺仿生设计作品。研究中以作品A作为核心案例进行数字转译、动态展示与交互验证，并结合课程中的其他作品检验系统在结构理解、方案比较和课堂辅助中的适用性。
实验使用版本以 Unity 2022.3.62f1 为运行环境，核心逻辑通过 C# 脚本完成，数据交换对象统一为 OrigamiModel JSON 文件。这样的实现路径使第四章形成的参数记录表能够直接衔接到系统读写、面片生成、约束建立与折叠展示环节，从而避免“方法章节”与“系统章节”之间脱节。
结合研究目标与当前工程实现，系统设计目标主要包括以下六个方面。
1. 实现折痕图的可视化构建。使用者能够在统一参考平面上完成顶点添加、折痕连接、顶点移动、删除与类型标记等操作，形成面向纸艺结构的二维几何描述。
2. 建立统一的数据表达方式。系统以 JSON 作为模型中间表示，统一管理顶点、面片、折痕、材质及全局参数，使设计环节与仿真环节能够围绕同一数据对象协同展开。
3. 实现三维模型的自动重建与动态模拟。系统依据折痕图数据自动生成三维面片、连接关系与物理约束，从而完成从平面构形到空间折叠行为的映射。
4. 支持可交互的参数调节与方案比较。使用者可对折叠角度、单元比例、连接间距和刚度假设等关键变量进行实时调整，并观察不同方案之间的表现差异。
5. 形成可复查的过程证据。系统对参数输入、状态变化、方案截图和观察记录进行同步留痕，为后续教学评价、实验比对和研究复核提供依据。
6. 为后续扩展预留接口。系统在现有框架中保留了折痕属性编辑、面片拓扑分析与更复杂参数控制等扩展空间，为后续研究深化提供技术基础。
5.2 系统整体架构
系统整体采用模块化架构，可分为数据层、设计编辑层、仿真执行层和交互展示层。该架构将纸艺构形记录、数字参数设定、物理求解与交互反馈进行相对分离，使模型逻辑与界面逻辑能够被统一管理，有利于后续扩展新的结构类型、参数选项与验证方式。

5.2.1 数据层
数据层负责保存纸艺结构的基础信息，是纸艺语言向数字语言转译的核心环节。系统以 OrigamiModel 作为统一容器，将顶点、面片、折痕、连接关系和材质属性整合为同一组结构化数据。其中，顶点用于描述折纸几何位置，面片用于记录顶点索引与可视化属性，折痕用于定义折线端点、折痕类型、角度范围与刚度参数，连接关系和材质字段则为后续扩展留下接口。
该层既支撑折痕设计阶段的数据保存，也支撑仿真阶段的模型读取，因此构成了整个系统的数据基础。通过将模型以 JSON 形式存储，系统能够在不同场景与模块之间维持稳定的数据交换关系。
5.2.2 设计编辑层
设计编辑层以折痕编辑模块为核心，负责在参考网格平面中完成折痕图构建。该层直接响应用户点击、拖拽与选择等操作，在二维平面中生成顶点对象与折痕线段，并保持其几何关系与类型标记的同步更新。
当前实现中，设计编辑层支持基于网格吸附的顶点创建、两点式折痕连接、顶点移动与关联折痕同步、顶点和折痕删除、山折与谷折等类型区分，以及折痕图的保存与反向加载。更重要的是，在保存过程中系统会自动调用面片生成模块，依据折痕网络推导闭合区域，由此完成从“点-边关系”到“面片关系”的初步拓扑组织。
5.2.3 仿真执行层
仿真执行层负责将折痕图转化为可运动的三维结构，是系统从几何模型过渡到动态展示的关键桥梁。该层首先读取 JSON 模型数据，生成面片对象、刚体组件、碰撞体与折痕线可视化对象；随后依据相邻面片共享折痕的关系建立铰链连接，并将各项折叠参数映射为可驱动的物理属性。
在控制机制上，系统通过统一的控制器维护全部有效折痕连接，将用户输入的折叠进度转化为关节目标角度，从而实现多折痕联动的折叠展示。由此，仿真执行层不仅承担了三维重建任务，也承担了结构行为演示与参数反馈任务。
5.2.4 交互展示层
交互展示层负责将建模过程、仿真状态和观察反馈转化为可理解的用户界面。该层主要包括设计模式与仿真模式切换、模型路径输入与重新加载、折叠滑条控制、场景相机浏览以及参考网格显示等功能。
在实验使用版本中，界面整体采用“左侧整体操作、中央模型、右侧编辑”的三栏布局，以减少学习者在操作过程中的视线跳转成本。
如图 5-1 所示，实验版系统总界面采用“三栏+双模式”的组织方式。该布局的重点不是增加界面复杂度，而是让“输入什么参数、生成什么结构、出现什么状态”能够在同一视域内被连续观察，从而更适合研究留痕、课堂演示与方案比较。

5.3.1 基于 JSON 的模型驱动机制
系统以 JSON 作为设计端与仿真端之间的桥梁。在设计模式下，折痕编辑结果被写入模型文件；在仿真模式下，加载模块再依据模型路径读取并解析该文件，完成数据重建。该机制降低了场景对象之间的直接耦合，使模型复用、版本保存、实验比较和后续扩展更加便利。
从研究方法角度看，JSON 机制的意义不仅在于数据存储，更在于将纸艺样机的构形信息、参数设定与仿真对象统一为可复查的数据记录，从而为多轮方案比较和教学留痕提供支撑。

5.3.2 基于半边思想的面片自动生成
折痕编辑阶段主要维护“点-边”关系，而仿真加载阶段则需要显式的面片信息。为解决这一问题，系统引入面片自动生成机制，在保存时根据折痕网络构造双向半边关系，按照顶点邻接顺序执行面遍历，从而自动识别闭合区域并生成有效面片。
这一机制避免了用户逐面手动标注的繁琐过程，使折痕图可以依据拓扑关系自动补全面片结构。同时，系统还对外部边界区域进行过滤，以降低将无效区域误识别为折纸面的可能性。该技术的引入显著提高了建模效率，也增强了纸艺构形向数字模型转译的连续性。
5.3.3 基于 Mesh 的折纸面重建
在三维重建过程中，系统将每个折纸面转换为独立的三维对象，并为其配置网格、渲染、刚体与碰撞等基础组件。面片几何依据顶点顺序生成三角形索引，再通过法线与包围盒更新完成网格计算。这样既能够满足实时渲染需求，也为后续物理仿真提供对象基础。
当前实现采用较为简洁的扇形三角化策略，即以面片首顶点为公共点构造三角形。该方法对于规则或近似凸多边形面片具有较高效率，适合本研究中的中小规模纸艺结构原型。
5.3.4 基于 Hinge Joint 的折叠仿真
在折叠行为模拟上，系统并未直接使用布料或软体求解，而是采用“面片刚体+折痕铰链”的方式建立折叠关系。具体而言，系统先识别共享同一折痕的相邻面片，再根据折痕方向、面片顺序及山折或谷折属性配置旋转轴、角度限制和弹簧参数，从而形成可控制的折叠机制[5]。
这一实现方式与纸艺结构“沿折痕旋转”的物理含义较为一致，能够在较低计算复杂度下表达折线驱动、面片联动和开合路径等关键特征。因此，它更适合作为设计研究与教学展示中的行为模拟方法，而非追求材料细观层面的高精度求解。
5.3.5 基于统一折叠进度的联动控制
为便于用户快速比较不同状态，系统采用统一折叠进度参数驱动全部有效折痕。当用户通过滑条或键盘输入改变折叠程度时，控制器会依据各折痕的角度范围线性计算目标角度，并同步更新关节目标状态。与此同时，系统还可根据当前关节状态反算整体折叠进度，实现界面值与物理状态之间的双向对应。
这一策略适合当前原型系统中“整体同步折叠”的实验需求。与逐条折痕独立求解相比，该方法更有利于控制变量、观察参数敏感性并形成可比较的方案结果。
5.3.6 参考网格与双面材质支持
除基础物理机制外，系统还考虑了几何参考与视觉表达的一致性。一方面，参考网格随相机视角同步更新，便于使用者在设计模式下进行对齐、测读与观察；另一方面，系统提供双面材质支持，使纸张正反面能够在视觉上得到区分，从而更清楚地呈现折叠后的空间关系。
这一部分虽然不直接参与折叠求解，但对于提升系统的可读性、可演示性和教学解释性具有重要作用。它使用户不仅能够“看到模型在动”，还能更准确地理解“结构是如何动的”。
5.4 交互设计与功能实现
在交互设计中，本文强调“建模-验证-比较”三类任务的连续衔接，使使用者能够在同一平台内完成从折痕构形到动态观察的完整流程。围绕这一目标，系统形成了以下几类主要交互机制。
5.4.1 设计模式交互
在设计模式下，用户围绕“顶点-折痕”两个核心对象展开操作。主要功能包括：在参考平面中添加顶点，通过两次选点建立折痕，拖动顶点并实时更新关联折痕，删除顶点或折痕，以及切换山折、谷折和边界折痕等类型。设计完成后，系统可将当前折痕图保存为模型文件，并支持后续重新加载。
为了保证编辑过程稳定，系统在顶点操作中引入了网格吸附与邻近点检测机制；在顶点删除后，还会同步调整相关索引与折痕引用关系，以避免几何关系错位。由此，设计模式不仅承担输入功能，也承担初步的数据整理功能。
5.4.2 仿真模式交互
在仿真模式下，交互重心转向模型加载、折叠控制和结果观察。用户可通过路径输入或模型选择方式读取目标 JSON 文件，再利用滑条或键盘调节整体折叠进度，使纸艺结构在不同展开状态之间切换。
该模式下的交互重点不在于复杂操作数量，而在于为结构比较和参数观察提供清晰入口。使用者能够在统一界面内快速切换模型状态，观察不同参数设定下的形态差异，从而支持方案筛选与设计优化。
为保证仿真结果不是单一终态截图，而是可比较的过程记录，系统将统一折叠进度下的关键帧序列作为最直接的运行证据。如图 5-4 所示，作品A至少保留起始、中间和终态三个关键状态，并尽量采用同一视角输出，便于横向比较不同参数组。

5.4.3 相机与观察交互
为满足空间结构观察需求，系统提供了完整的场景浏览能力，包括前后左右移动、上下平移、旋转观察、缩放浏览与视角重置等操作。通过自由视角控制，使用者可以从不同方向审视折叠结构在各阶段的空间关系，并在关键位置停留观察局部构造。
这一观察机制对于纸艺结构研究尤为重要。由于许多折叠关系具有明显的空间层次，仅依靠单一视角难以理解其开合逻辑，而交互式相机能够有效提高结构可解释性。
5.4.4 双模式切换机制
为增强操作流程的清晰性，系统将设计模式与仿真模式进行显式区分，并通过界面显示与功能启停机制完成切换。设计模式主要面向折痕图构建与参数输入，仿真模式则主要面向三维折叠展示、动态观察与结果验证。两种模式围绕同一数据模型衔接，形成较清晰的任务分工。
这种双模式组织方式符合交互式仿真系统中“先建模、后验证”的操作逻辑，也使系统更适合用于教学演示与实验记录。
5.5 仿真边界与适用范围
由于标题中保留“机械仿真”表述，因此有必要在正文中进一步界定本文的仿真边界。本文所讨论的机械仿真，主要是服务于纸艺结构设计应用和课程创作辅助的交互式数字仿真，重点解决结构理解、参数探索、动态展示和方案比较等问题，而非直接替代高精度工程分析。
5.5.1 适用范围
结合当前实现，系统更适用于以下场景。
1. 课程中的半立体纸艺作品或中小规模纸艺结构的教学演示。
2. 折痕、翻起与层叠等结构关系及联动机制的可视化验证。
3. 基于统一模型数据的快速原型设计、方案比较与展示推演。
4. 山折、谷折、边界折痕等基本折痕类型及其空间转换关系的建模与动态观察。
5.5.2 当前边界
与此同时，当前系统仍存在以下边界。
1. 现阶段仿真控制以“整体统一折叠进度”为核心，尚未实现每条折痕的独立驱动，因此更适合联动演示，而不适合复杂工序级折叠过程模拟。
2. 相邻面片关系的重建目前仍主要依赖折痕端点共享关系，预留的连接字段尚未成为独立约束来源，因而在复杂连接场景中仍有扩展空间。
3. 面片三角化当前采用较简化的扇形划分策略，对于凹多边形或复杂面片，网格重建的稳定性仍然有限。
4. 折叠仿真基于刚体与铰链机制，在折叠幅度较大、面片较多或碰撞关系复杂时，仍可能出现穿模、抖动或局部不稳定现象。
5. 材质与颜色参数虽然已纳入数据结构，但运行阶段尚未完全实现按模型参数自动构建渲染效果，部分显示结果仍依赖预设材质。
6. 折痕属性编辑、平折类型与更复杂拓扑控制等扩展能力虽已在框架中预留，但当前尚未全部贯通至完整交互流程，说明系统仍处于实验性集成阶段。
7. 设计模式与仿真模式之间当前主要通过文件存储实现衔接，保存后若需立即验证最新模型，仍需经过重新加载过程。
因此，本文更倾向于将该系统定位为“中间层仿真工具”：其上承接纸艺样机、课程创作与仿生观察，其下可进一步连接高精度工程分析。这个定位既解释了系统为何适合设计前期、概念验证、教学实验和展示推演，也限定了本研究结论的适用范围。
5.5.3 当前不能做什么
为与题目中的“机械仿真”表述形成边界闭环，本文进一步将当前系统“不能做什么”单列说明如下。
1. 不能直接输出应力、应变、承载能力或疲劳寿命等工程定值结果。
2. 不能精确描述纸材厚度、塑性折痕、材料损伤、湿度影响等复杂材料行为。
3. 不能替代逐条折痕独立驱动、多工序顺序折叠或复杂装配路径规划。
4. 不能保证在高密度拓扑、大角度折叠或复杂碰撞条件下始终无穿模、无抖动、无局部失稳。
5. 不能单独作为工程级验证依据，仍需与实体试作、材料测试或有限元分析协同使用。
上述限制说明，本文系统更适合承担“设计前期验证”和“教学中间层解释”的角色，而不宜被表述为替代工程仿真的最终平台。也正因为边界清晰，题目中的“机械仿真”在本文中才更准确地指向一种服务于结构理解、参数比较和方案反馈的交互式数字仿真。
5.6 本章小结
本章围绕基于 Unity 的交互式仿真系统设计，对系统目标、模块架构、参数映射、关键技术、交互机制及适用边界进行了系统梳理。通过系统总界面图、参数映射示意图、完整实现链示例、JSON 字段样例和关键帧序列图，本文进一步将“折痕输入-JSON 保存-面片生成-铰链建立-折叠展示”的过程落实为可追踪的实现闭环。
总体来看，该系统可作为连接实体纸艺样机、数字参数比较与教学展示的重要中间环节，为下一章的实验验证与案例分析提供技术基础；与此同时，通过单列“当前不能做什么”，本章也明确限定了系统仍属于设计应用和教学验证层面的交互式数字仿真，而非工程级机械分析平台。
第六章 实验与验证
6.1 实验设计思路
为检验第五章所构建交互式仿真系统在结构认知、参数比较与教学应用中的支持作用，本章设置三组探索性实验。考虑到研究仍处于原型验证阶段，实验材料主要来自课程中的多种半立体纸艺仿生作品，且样本规模较小，本章以原始答卷、计时记录、系统截图、观察表、问卷回收表和开放式反馈为基础，以描述性统计与过程记录为主，并在条件允许的比较中补充简单非参数检验作为方向性参考。
实验对象为设计相关专业课程中的参与学生，共 10 人。参与者均具备基础三维造型或设计表达经验，但未系统接受过折纸工程或 Unity 交互仿真训练。围绕研究目标，实验分别从结构理解、参数探索与教学应用三个维度展开，并结合课程中的多件半立体作品组织任务。对应评价指标包括任务正确率、完成时间、理解评分、稳定性评分、操作流畅性、理解难度、学习兴趣和学习意愿等。

6.2 实验一：结构理解验证实验
6.2.1 实验目的
本实验旨在考察交互式仿真系统是否有助于使用者更快理解纸艺结构展开路径、关键连接位置及参数影响关系。
6.2.2 实验对象与分组
从课程中的半立体纸艺仿生作品中选取 3 件结构关系较清晰、包含折叠与翻起特征的代表性样本作为实验材料，统一编号为 S1-S3，将 10 名学生随机分为两组，每组 5 人。A 组采用传统二维图示与实体纸样进行观察和学习，B 组采用第五章所述 Unity 交互式仿真系统进行观察和学习。两组学习时长均控制在 15 分钟以内，任务说明和答题要求保持一致。由于本实验未设置前测或能力基线，因此随机分组主要用于尽量平衡个体差异，结果仅用于比较统一任务条件下的组间表现。实验一的原始数据来源包括任务答卷、现场计时表、统一评分表和参与者自评单，整理方式与被试编号规则与第三章保持一致。
6.2.3 实验任务
实验要求参与者围绕所提供的代表性作品样本完成三项任务，分别为描述结构展开方式、指出关键连接部位以及判断参数变化对形态的影响。整个流程分为四步：首先由研究者用约 1 分钟说明任务与答题要求；随后参与者进行约 7 分钟的自主观察与学习；观察结束后立即进入约 5 分钟的作答阶段；最后在约 2 分钟内完成理解评分自评与材料回收。为尽量反映即时理解效果，任务完成后需立即提交答案，不允许返回前一环节重复查看资料。
6.2.4 评价指标
评价指标包括任务正确率、完成时间和主观理解评分。原始数据分别来自任务答卷、现场计时表和实验后即时自评。为保证评分口径一致，实验一在正式执行前先固定统一评分表，其样例如表 6-1a 所示。

6.3 实验二：参数探索与设计优化实验
6.3.1 实验目的
本实验旨在考察交互式仿真系统是否能够帮助使用者更直观地比较不同参数方案，并识别相对合理的结构区间。
6.3.2 实验方法
以作品A这一折叠角度变化较为明显的半立体结构为基础，在 Unity 环境中分别设置不同折叠角度，并观察结构稳定性与交互反馈。实验材料包括作品A的数字模型、参数记录表、稳定性观察表、运行截图编号和参与者操作流畅性评分单。每一参数组均连续运行三轮，三轮均在相同视角和相同控制方式下执行；研究者在每轮结束后记录是否出现明显穿透、局部塌陷和联动不顺等现象，并保存关键帧截图；参与者在观看各参数组运行后分别填写操作流畅性评分。该实验的重点不在于获得材料力学意义上的最优值，而在于验证系统是否具备支持参数比较与方案筛选的能力。
6.3.3 实验变量
自变量为折叠角度，设置为 15°、30° 和 45°。之所以选择这三组角度，主要基于两点：其一，这三档角度分别对应低、中、高三个可辨识的开合区间，便于在同一作品上观察差异；其二，前期调试显示，低于 15° 时结构状态差异不够明显，而高于 45° 时作品A更易出现自接触并干扰统一比较，因此最终选取 15°、30° 和 45° 作为可比参数组。因变量为结构稳定性评分与操作流畅性评分。具体说明如下。
1. 稳定性评分：由研究者依据统一观察记录表，根据结构运动连续性、终态保持性和局部干涉情况，按 1-5 分进行描述性赋值，并综合三轮运行情况形成最终记录。
2. 操作流畅性评分：由参与者根据界面响应、操作易懂程度和反馈连贯性进行 1-5 分评分。

6.4 实验三：教学应用效果验证
6.4.1 实验目的
本实验旨在考察“纸艺样机观察+交互式仿真操作”的学习方式，是否在理解难度、学习兴趣和学习意愿方面呈现出比传统方式更积极的主观评价倾向。
6.4.2 实验对象
选取 10 名设计相关专业学生，分别体验传统学习方式与交互式仿真学习方式。为降低顺序效应的影响，将 10 人分为两个顺序组，其中 5 人先体验传统方式再体验 Unity 方式，另外 5 人采用相反顺序。
6.4.3 实验方法
实验分为两个阶段。第一阶段，学生通过传统讲解与纸样观察完成对课程代表性作品的学习；第二阶段，学生通过 Unity 系统对同类作品进行交互式观察、比较与操作。为降低顺序效应影响，实验将参与者分为两种体验顺序，并尽量保持两阶段的任务说明、观察时长和作品类型一致。每种方式的观察与操作时间均控制在 10 分钟内，完成两种体验后统一用约 5 分钟填写由 3 个封闭式核心条目和 1 个开放式反馈题构成的 Likert 五级量表问卷。实验三的原始数据来源包括 10 份回收问卷、10 条开放式反馈、观察记录和顺序分组表。本研究未对学习迁移和顺序效应进行单独统计剥离，因此相关结果主要用于描述短时体验差异。
6.4.4 问卷指标
问卷指标包括理解难度、学习兴趣和学习意愿。其中，理解难度分值越低表示理解越容易，学习兴趣与学习意愿分值越高表示教学体验越积极。问卷围绕上述三项指标分别设置 3 个核心条目，并配合 1 个开放式意见题收集补充反馈。由于这 3 个条目分别对应不同维度，且样本量仅 10 人，本文不进行内部一致性信度分析，而以原始分数、均值、标准差和开放式反馈作为探索性解释依据。问卷原文如表 6-4a 所示，各指标含义整理如表 6-3 所示。

6.4.6 结果分析
从原始问卷、均值、标准差和开放式反馈看，Unity 方式在三项指标上的评分方向整体上更为积极，其中理解难度均值低于传统方式，学习兴趣和学习意愿均值则高于传统方式。开放式反馈进一步说明，参与者更容易借助三维交互界面辨识折线与面片之间的空间关系，也更容易将“参数变化”与“形态结果”建立对应。补充符号检验所反映的方向一致性与上述描述性结果相符。
但本实验主要反映短时体验后的主观感受，尚未对长期学习成效、课程成绩或跨课题迁移能力进行持续跟踪，也未对顺序带来的潜在迁移效应进行单独分析。因此，相关结果更适合被理解为纸艺仿生与交互仿真结合在教学应用场景中初步呈现出的积极趋势，而非稳定的教学效果结论。
6.5 综合分析
三组实验从不同侧面验证了第五章所构建系统的应用价值，综合来看主要体现出以下几个方面。
1. 在结构理解层面，交互式仿真在当前样本条件下初步呈现出有助于认知效率的趋势，尤其能够帮助使用者理解课程中半立体作品的展开路径、连接位置与参数影响之间的对应关系。
2. 在参数探索层面，可视化调节机制有助于较快识别作品A中的相对合理方案区间，并降低重复建模带来的试错成本。
3. 在教学应用层面，纸艺样机与数字仿真结合初步呈现出改善学习体验的趋势，使结构认知、参数记录和设计表达之间形成更连续的学习链路。
4. 在研究方法层面，实体纸样、参数日志、交互截图和问卷结果能够共同构成较为完整的过程证据链，这也是本文相较于单纯作品展示的一项重要改进。
需要进一步说明的是，由于当前实验样本量较小、未设置前测、实验三顺序效应未剥离，且部分指标依赖单评分者观察，本章结论更适合被理解为对“纸艺仿生-交互仿真”研究路径可行性的初步验证，而非普遍适用的最终结论。若要进一步增强论证力度，后续研究仍需增加样本量、扩展结构类型，并引入更严格的物理测试或工程仿真对照。
6.6 本章小结
本章通过结构理解、参数探索和教学应用三组实验，对纸艺仿生与交互仿真结合路径进行了探索性验证。基于原始答卷、评分表、计时记录、参数观察表、问卷与开放式反馈，本章认为该路径在结构解释、方案比较和教学支持方面初步呈现出积极趋势，尤其适合作为设计前期与教学阶段的中间层方法。与此同时，受限于样本规模、未设置前测、顺序效应未剥离以及工程验证深度，本章结论仍主要停留在方法可行性与应用潜力层面，尚有待在后续研究中进一步完善。
第七章 融合设计方法与教学应用策略
7.1 “纸艺仿生-交互仿真”设计方法模型
基于前文研究，本文将纸艺仿生与交互仿真整合为一条面向设计前期与教学场景的中间层方法链。该模型由五个连续环节构成：仿生提取、纸艺表达、数字建模、交互仿真和应用验证。其核心特征不是直接输出工程性能结论，而是将自然原型、实体样机、参数记录与交互结果组织为连续证据链，使结构判断、参数比较和方案修正能够被解释与复核。
相较于“先画效果图、后做验证”的单向路径，该模型强调在实体样机与数字环境之间不断往返：通过纸艺样机快速显化结构问题，通过参数记录固定关键变量，再通过仿真界面集中比较状态差异，最终形成可追踪的迭代闭环。也正因为如此，本文所说的方法价值更适合限定在结构理解、方案比较和教学支持层面，而不宜外推为工程级机械仿真的替代路径。
7.2 融合设计流程构建
在具体操作中，融合设计流程可概括为以下五步。
1. 问题定义与仿生目标确定。明确研究对象、设计需求与评价边界，输出自然原型观察记录和结构关键词。
2. 纸艺构形与原型试制。通过纸艺技法形成基础结构样机，并同步记录关键尺寸、折线类型和修正过程。
3. 数字建模与参数设定。完成结构单元拆解、参数重构和 JSON 模型生成，建立可用于比较的数字对象。
4. 交互仿真与方案验证。通过系统观察运动过程、参数敏感性和结构差异，输出关键帧截图、操作日志和比较记录。
5. 优化迭代与应用转化。根据纸样与仿真结果对结构进行调整，并形成版本比较说明，用于展示、包装、装置或教学任务等情境。
这一流程更适合服务于“先理解结构、再比较方案、后决定是否深化”的设计节奏。换言之，它强调的是把设计判断建立在一系列可追踪中间结果之上，而不是在一开始就直接追求最终工程结论。
7.3 过程性证据组织原则
结合前述方法和实验经验，正式提交版本中的过程性证据宜优先组织为以下五类。
1. 原型观察证据。包括自然原型图、草图、关键词提取和结构分析记录，用于说明仿生来源是否清晰。
2. 样机试作证据。包括纸样、面片编号、折线类型标注和失败-修正对照，用于说明结构是否经过实体校验。
3. 参数转译证据。包括参数表、尺寸校对表、JSON 字段样例和样机-数字模型对应关系，用于说明转译路径是否可复查。
4. 仿真运行证据。包括系统界面图、关键帧序列、状态提示和参数比较记录，用于说明系统是否真正支持结构观察与方案筛选。
5. 应用验证证据。包括实验答卷、评分表、原始数据、问卷与开放式反馈，用于说明研究判断建立在何种证据基础上。
这些证据的作用不在于简单堆叠材料，而在于保证每一步设计决策都可以回溯到具体来源。对本研究而言，过程性证据比单一终态效果图更能支持“方法是否成立、系统是否实现、结论是否审慎”的评审判断。
7.4 教学模式设计
在教学应用层面，该方法可转化为项目驱动式教学路径。结合前述实验经验，教学实施可分为基础认知、结构构形、数字转译、交互验证和成果展示五个阶段。其较适合用于结构认知、概念验证和前期方案推演类课程，而不宜替代以材料工艺或工程计算为主的课程模块。
教学目标主要包括三类：其一，帮助学生理解复杂结构关系与开合逻辑；其二，培养从实体试作到数字验证的设计方法意识；其三，增强学生在方案比较、证据表达和过程复盘方面的能力。
在评价方式上，应重视过程性评价。除最终作品外，还应纳入纸样记录、参数表、仿真截图、版本比较、操作日志与反思说明等证据，使学习结果能够被追踪和解释。若在课程中推广，建议将“结构解释准确性”“参数记录完整性”“方案迭代依据”和“最终呈现质量”分别设为独立评价项，以避免课堂考核重新滑回只看结果图面的旧模式。
7.5 教学应用案例
本文以课程中的半立体纸艺仿生创作为案例，对方法路径进行应用说明。案例要求学生完成自然原型分析、纸艺结构试制、数字建模、Unity 演示与方案优化五项任务，并在每一阶段提交对应的过程证据。案例显示，学生在提交参数记录、仿真截图与反思说明后，能够较清楚地说明结构来源、空间层次、展开逻辑和参数变化原因。这一现象表明，该路径在当前课程情境下有助于把“会做一个作品”进一步转化为“能解释一个结构方案”。
从教学组织角度看，该案例的价值并不主要体现在最终展示效果，而在于它让学生在纸艺样机、参数记录表和交互界面之间建立起连续映射关系。这样一来，教师不仅能看到学生“做出了什么”，还能看到学生“为什么这样调整”和“依据什么进行优化”。不过，这一案例仍属于单一课程情境中的应用说明，其教学效果判断仍应与第六章的小样本、趋势性结论保持同一证据强度。
7.6 方法特点与适用边界
综合前文，本文方法的主要特点体现在以下几个方面。
1. 可视化程度较高。结构关系、关键状态和参数变化能够被较直观地展示。
2. 试错成本较低。纸艺样机与交互系统均适合快速试作与多轮比较。
3. 过程证据较完整。样机、参数表、JSON、关键帧和问卷可以形成连续记录链。
4. 设计与教学适配性较好。更适合设计前期、结构认知和课堂演示场景。
与此同时，本文方法的适用边界也应明确如下。
1. 它更适用于概念设计、结构理解、课程实验和展示推演，不宜直接承担工程定值分析任务。
2. 当前系统对复杂材料行为、厚度效应和高密度碰撞关系的表达仍较有限。
3. 方法运行仍依赖研究者或教师具备一定数字化表达和记录能力。
4. 其最适用的对象仍是中小规模、结构关系相对清晰的半立体纸艺样本。
5. 若需进入工程应用阶段，仍应与实体试作、材料测试或有限元分析协同使用。
上述边界再次说明，本文所说“机械仿真”在本研究中应理解为服务于结构理解、参数比较和方案反馈的交互式数字仿真，而非面向承载预测和材料响应的工程级仿真。
7.7 本章小结
本章在前文研究基础上，将纸艺仿生与交互仿真整合为可执行的方法模型、流程组织和教学策略，进一步强调了过程性证据的组织原则及其适用边界。整体上看，该路径更适合作为设计前期与教学阶段的中间层方法，其价值在于增强结构解释、方案比较和证据表达，而不在于替代工程级仿真分析。
第八章 研究成果与应用价值
8.1 主要研究贡献
综合全文，本文的主要研究贡献可压缩为以下三点。
1. 在方法层面，提出了“仿生提取-纸艺构形-参数建模-交互仿真-应用验证”的连续链路，补足了纸艺样机与工程分析之间长期缺位的中间层方法。
2. 在系统层面，构建了基于 Unity 的交互式仿真原型，并以 JSON 为中间对象形成从折痕输入到折叠展示的可复查实现链。
3. 在验证层面，围绕结构理解、参数探索和教学应用组织了小样本实验，形成了由任务答卷、评分表、运行记录、问卷与开放式反馈构成的过程证据链。
8.2 方法与系统成果
在更具体的成果层面，本文形成了以下三项可直接落地的产出。
1. 建立了“结构单元拆解+参数约束重构”的纸艺数字建模思路，并通过作品A完成了样机到数字模型的示范链。
2. 构建了可用于半立体纸艺作品动态展示、参数调节和方案比较的系统原型，明确了其适用范围与当前不能做什么。
3. 形成了与系统实现相配套的参数表、JSON 字段样例、关键帧记录和实验评价材料，为正式送审版本的可复核性提供了基础。
8.3 应用价值与边界
本文的应用价值主要体现在两个层面。其一，在设计前期，纸艺样机与交互仿真结合有助于更快比较方案差异、发现结构问题并组织修正依据；其二，在教学场景，过程性证据组织和可视化比较机制有助于支持结构认知与方案表达。需要强调的是，这里的“应用价值”主要建立在趋势性实验结果和案例说明之上，因此更适合被理解为可行性支持，而不是已经充分证明的普遍结论。
8.4 对设计学科的启示
本文对设计学科的启示在于，纸艺不仅可以作为造型媒介，也可以作为连接仿生观察、实体试作、数字建模和交互验证的复合媒介。通过引入参数记录和过程证据，设计研究能够更清楚地回答“为什么这样做”和“依据什么调整”，从而推动设计基础课程与数字工具之间形成更紧密的工作链路。
8.5 应用前景分析
若后续能够补充更多样本、完善实验记录并与工程仿真形成分层协同，纸艺仿生与交互仿真结合路径可进一步拓展至以下方向。
1. 展示装置与空间构件的概念设计。
2. 环保包装和可展开结构产品的前期方案研究。
3. 设计基础课程、工作坊和跨学科教学项目。
4. 与专业工程仿真平台协同，形成由概念生成到精细分析的分层验证体系。
第九章 结论与展望
9.1 研究结论
基于全文研究，本文的结论可压缩为以下三点。
1. 纸艺仿生结构适合作为连接仿生观察、样机试制和数字建模的中间媒介；通过“仿生提取-纸艺构形-参数建模-交互仿真-应用验证”的路径，可以较清楚地完成从自然原型到数字对象再到设计验证的过渡。
2. 基于 Unity 的交互式机械仿真在本研究中更适合被定位为中间层数字工具，其主要作用是支持结构理解、参数比较和方案反馈，而不应被解释为对工程级力学分析的替代。
3. 小样本探索性实验和课程案例说明，该路径在结构解释、参数筛选和教学支持方面初步呈现出积极趋势，但这一判断应限定在样本量较小、无前测、顺序效应未剥离且部分指标依赖单评分者的研究条件下理解。
9.2 研究不足
本文仍存在以下不足。
1. 实验样本量较小，验证结论的外部效度仍有待增强。
2. 当前仿真系统侧重结构运动展示和参数比较，对复杂材料行为、厚度效应和高密度碰撞关系的表达仍较有限。
3. 本文尚未引入高精度工程仿真、物理测试数据及多评分者一致性检验，因此在承载与力学性能层面仍应保持谨慎表述。
4. 案例应用仍以课程中的半立体作品、教学与概念验证场景为主，面向产业和工程应用的深度案例有待补充。
5. 报告中的部分图件、流程图和原始记录虽已在正文中交代结构，但在正式排版时仍需进一步补齐与统一。
9.3 后续研究方向
后续研究可从以下几个方向展开。
1. 扩大样本范围，结合更多专业背景和更多轮次实验，增强研究结论的稳定性。
2. 引入更细化的参数记录与评价指标，建立纸艺样机与数字模型之间更精准的映射机制。
3. 探索与有限元分析、专业多体动力学软件及实体测试的协同路径，形成分层仿真体系。
4. 继续完善系统界面图、结构运动序列图和标准化实验附件，增强正式版本的可复核性与展示质量。
5. 将方法扩展到包装、展示、装置和机器人概念设计等更具体的应用场景中，检验其外部转化能力与适用边界。
