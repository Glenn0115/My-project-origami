## 2. 结构设计

### 2.1 顶点布局（25个）
```
中心顶点（V1）：(0, 0, 0)
内环顶点（V2-V13）：12个，半径3.0，每30°一个
外环顶点（V14-V25）：12个，半径6.0，每30°一个
```

### 2.2 折线系统（54条）
**中心辐射山折线（6条）**
- V1→V2, V1→V4, V1→V6, V1→V8, V1→V10, V1→V12
- 类型：Mountain (type=1)
- 角度：-60° ~ +60°
- 功能：控制整体收拢

**内环谷折线（12条）**
- V2→V3→V4→...→V13→V2（闭合环）
- 类型：Valley (type=0)
- 角度：-90° ~ +90°
- 功能：花瓣柔性过渡

**外环对角山折线（6条）**
- V3→V15, V5→V17, V7→V19, V9→V21, V11→V23, V13→V25
- 类型：Mountain (type=1)
- 角度：-75° ~ +75°
- 功能：控制尖端展开

**外环边界线（30条）**
- 类型：Boundary (type=2)
- 功能：定义结构边界

### 2.3 面片划分（18个）
- **内层花瓣**（6个）：F1-F6，每个由中心+2个内环顶点构成
- **外层花瓣**（12个）：F7-F18，连接内外环的梯形面

### 2.4 关键参数
| 参数 | 含义 | 值 | 用途 |
|-----|------|---|------|
| θr | 中心辐射折角 | ±60° | 控制收拢幅度 |
| θv | 内环谷折角 | ±90° | 控制花瓣柔性 |
| θd | 对角展开折角 | ±75° | 控制尖端展开 |
| r1 | 内环半径 | 3.0 | 花瓣基部尺度 |
| r2 | 外环半径 | 6.0 | 花瓣展开尺度 |
| n | 花瓣数量 | 6 | 对称性 |
